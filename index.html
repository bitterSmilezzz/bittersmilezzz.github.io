// 03.5 FIELD NOTES

做的时候踩到的坑

这一站本身就是作品。以下都是这个仓库里真实发生过、量出来过的。

012026-10

hidden 不是万能锁

给容器写了 display: flex，它就盖过了浏览器默认的 [hidden] { display: none }。会话入口子栏在「任务执行态」下藏不住， 实测 hidden=true 却仍有 40.5px 高度。 显式补一条 [hidden] { display: none } 才算真收口。

CSS · 属性优先级

022026-10

「永远深色」的块，别用会变色的墨

灵动岛胶囊底恒为黑，里面的强调色却跟着主题走。浅色主题那支 #059669 压在 12% 白罩的黑底上（实际渲染 rgb(31,31,31)），合成后只有 4.39:1，差 4.5 一线。 改用不随主题变化的墨色后达标。

设计令牌 · 对比度

032026-10

过渡还没跑完，别急着读颜色

验证三态指示灯时，三种状态的颜色读出来一模一样，差点当成缺陷去修。 真因是 getComputedStyle 在过渡进行中返回的是插值中间值—— 点击后立刻读，读到的是起点色。等过渡结束再读，三态才各自成立。

测量方法 · 假阳性

042026-10

「元素可见吗」不能只看它自己的 display

getComputedStyle(el).display 不继承祖先的 display: none。父容器已隐藏时，子元素仍报 block， 于是「无 JS 时还有几个死控件」数出来是三个，实际是零。 要用 getClientRects().length 这类真实渲染判据。

可访问性 · 判定口径

052026-10

声明的对比度 ≠ 渲染出来的对比度

上一轮把小字从 1.49:1 修到 4.63:1，结论写「读得清」， 还附了一句「blur(2px) 不改变实测对比度」。 那句话没被验证过，而它是错的——对比度按 CSS 颜色算， blur 改的是渲染像素。11.5px 的中文字笔画约 1px，2px 半径比笔画还宽， 字形直接糊掉。改用逐像素算相对亮度才量得出来。

测量方法 · 自我推翻

062026-10

调 opacity 让内容「退后」，这条路走不通

想让非活跃行淡下去，把 alpha 从 0.30 一路扫到 1.00—— 小字要够 4.5:1，所需 alpha 恰好是 1.00（0.85 时才 4.19:1）。 根因是墨色满强度也只有 5.42:1，没有余量供衰减， 而 opacity 是作用在整行上的。改成明度分档后层次差从「1.49 vs 17.12」变成「5.42 vs 17.12」。
